# Keep chats in a project (/docs/user/everyday-use/keep-chats-in-a-project)

## ✍️ Steps [#️-steps]

1. In **Chat**, find **Projects** in the chat list. Tap **See all projects**.
2. Tap **Create**.
3. In **Project settings**, type a **Project name**. Add a **Description** and **Instructions** if you like.
4. Tap **Save**.
5. Tap the project's name to open it and chat inside it.

## 🔍 Find and change one [#-find-and-change-one]

Type in **Search projects** to narrow the list. Tap the pencil to change a project. If it is yours, you can also pin it, or tap **Delete project**. Deleting a project keeps its chats.

**Instructions** shape the answers in that project.

## 👨‍👩‍👧 Good to know [#-good-to-know]

Children cannot create projects. The page is hidden while Incognito is on.

## 🙋 Still need help? [#-still-need-help]

If the **Create** button is missing, you may be signed in as a child. Ask the person who runs the house.
