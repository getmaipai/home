# Send a message (/docs/user/everyday-use/send-a-message)

## ✍️ Steps [#️-steps]

1. Tap **Chat** in the main menu.
2. Tap **New chat** to start fresh, or tap an older chat in the list to keep going.
3. Click the box that says **Send a message...**
4. Type your question.
5. Press Enter, or tap **Send message**.
6. Read the answer as it appears.
7. If you scrolled up, tap **Scroll to bottom** to jump to the newest text.

## 📎 Adding a file [#-adding-a-file]

Tap the **+** button (**Add Attachment**) next to the box to add a file or picture to your message.

## 🔎 Find an old chat [#-find-an-old-chat]

Tap **Search chats** and type a word from the chat you want.

## 🏷️ Rename or delete a chat [#️-rename-or-delete-a-chat]

Open the chat, then tap the menu at the top, called **Conversation actions**. Pick **Rename** or **Delete**. For more on deleting, see [Forget something](/docs/user/privacy-and-safety/forget-something).

## 🙋 Still need help? [#-still-need-help]

If no answer comes, see [If chat does not answer](/docs/user/fix-a-problem/chat-does-not-answer).
