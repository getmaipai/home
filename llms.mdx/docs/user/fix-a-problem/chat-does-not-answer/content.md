# If chat does not answer (/docs/user/fix-a-problem/chat-does-not-answer)

## ✍️ Steps [#️-steps]

1. Wait a minute. The first answer after a restart can be slow, and you may see **Starting your AI…**.
2. If an error shows, tap **Retry**.
3. Reload the page and send the message again.
4. Open **Home** and look at the **Repairs** card. A number means something needs fixing.
5. Open **Repairs**. Each row says what is wrong and how to fix it.

<Shot id="repairs" />

6. If a repair needs an admin, tell the person who runs the house.

Admins also see **Error details** on a failed answer. Send those to whoever helps with the house.

## 🔁 Try a fresh start [#-try-a-fresh-start]

Tap **New chat** and ask something short. If that works, the old chat may be the problem.
