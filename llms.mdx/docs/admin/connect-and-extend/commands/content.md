# Create a command (/docs/admin/connect-and-extend/commands)

A command fires only on the exact phrase. It never guesses.

## ✍️ Steps [#️-steps]

1. Open **Settings**, **Voice**, then the **Commands** card. Tap **Create a command**. Adults and above can do this.
2. Type a **Trigger phrase**, such as "movie night".
3. Under **Who can trigger this command**, pick the lowest role.
4. Under **What this command does**, pick one:
   - **Say something back**: type what MaiPai says, and optionally a spoken version.
   - **Control a smart-home device**: type the Home Assistant domain, the service and the entity id.
5. Tap **Create command**.

## 📋 Manage the list [#-manage-the-list]

Owners and admins open **Home settings**, then **Commands** to see **Household commands**. Each row shows its phrase, its action and the role needed. Tap **Delete** to remove one. You can delete your own commands. Owners and admins can delete any.

If it fails, Home says "Could not create that command." or "Could not delete that command."
