Settings reference

Every household and per-person setting, its default and what it changes.

How to read this page

Home settings are set once for the household. Person settings belong to one person, and the guardian rules decide who may change them for a child or teen. Level is basic, advanced or expert; the app hides higher levels until asked. A blank "What it does" means the screen explains it in place. Settings marked "Not active yet" are saved but nothing reads them today. Robot and vision settings (keys starting robot., person.robot., person.vision. and vision.) are used by MaiPai Bot, not by Home itself.

One more setting, Wake word listening (voice.wakeword.enabled, device scope, default off), appears only when the wake-word files are installed, so it is not in the tables. Only owners, admins and adults see it. The one detector today is openWakeWord "Hey Jarvis", and it runs in the browser. No setup screen downloads the wake-word files; the setting stays hidden until all four are on disk in the voice/wakewords data folder (see Where your data lives).

Each table gives the label as shown, the key (useful in a support report), the default, the level and what it does. For the same screens in plain language, see the user guide.
