# See what has an update

Owners and admins can see what is up to date and what has a newer version.

## Look at the list

1. Open **Settings**, then **Backups, storage and updates**.
2. Open the **Maintenance** tab and choose **Updates**.

Each row shows the part's name, the version you have, the newest version, when Home last looked, and a status. The status says **Update available** or **Up to date**. The list can include MaiPai Home itself, the AI engine parts, models, offline books and your robots.

Home looks for new versions by itself each day.

## Update an engine part

1. Find the engine row that says **Update available**.
2. Open its **More actions** menu and choose **Apply**.

Home swaps in the new build and checks that it works. If the swap fails, Home goes back by itself and shows a message.

## Go back to the old version

Right after you apply an update, the same menu has **Go back**.

1. Choose **Go back**.
2. Press **Confirm**.

Home returns to the version you had before.

## Update MaiPai Home itself

The Updates page shows when a new MaiPai Home is out. You install it as described in [Install, upgrade, uninstall and fix the install](install-upgrade-uninstall.md), which also explains how to go back a version.

## Get a message when an update is out

You can ask for a Telegram message when a MaiPai Home update is out. See [Notifications](notifications.md).

If you are not an owner or an admin, the page says only an owner or admin can manage updates.
