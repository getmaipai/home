# The Library

The Library holds every picture, video, song and file you can see in Home. Open it from the folder icon in the left rail.

## Find a file

On a wide screen the sections are in a column on the left: **All files**, **Pictures**, **Videos**, **Songs** and **Documents**, then **Shared with me**, **Shared by me**, **Only me** and **Trash**. Each shows how many files it holds. On a phone the same sections are chips at the top and in the menu.

- Type in **Search your Library** to find a file by its name or by what you asked Home to make. Press **/** to jump to the box.
- **Mine** shows only the files you added or made.
- **Only me** shows your files that you have not shared.
- **Newest** lets you sort by newest, oldest, name or largest.
- The two buttons next to it switch between big pictures and a list.

The address in your browser remembers what you picked. Send that address to someone in your home and they see the same view of the files they are allowed to see.

## Look at a file

Pick a file to open it big. Use the arrow keys, or the arrows on screen, to move to the next file. Press **Esc** to close. The **i** button shows details: its size, who made it, who can see it and how long Home will keep it.

Pictures zoom with the **+** and **-** buttons. Videos and songs play right in the window.

## Add a file

Pick **Upload**, or drag a file onto the page. You can add pictures, videos, songs, PDFs, office documents and plain text, up to 500 MB each. A card shows how far each file has got. If a file is refused, the card says why and what to do.

A child sees **Ask to add a file**. A grown-up adds the file for them.

## Share a file

Open the file and pick **Share**. Turn on the people in your home who may see it, or **Everyone in the home**. Turn it off again to stop sharing. They lose access right away.

**Send** uses your phone or computer's own share sheet, so you can text the file or use AirDrop or Mail. Home makes no link that works outside your home.

A child cannot share. A picture marked for adults only is never shown to a teen or a child.

## Keep, rename and delete

- **Keep** stops Home from ever removing a file to make room. Files you add yourself are always kept.
- **Rename** changes the name you see. Leave it empty to go back to the name Home chose.
- **Mark all-ages** appears for an adult on a picture marked adults only. Home checks the picture again, and only changes the mark if it is sure the picture is fine for everyone.
- **Delete** moves a file to **Trash**. A message with **Undo** appears. Trash keeps it for 30 days. Open **Trash** in the Library to **Restore** a file or **Delete forever**.

To work on many files at once, pick **Select** (or press **S**), tick the files, and use **Share**, **Keep** or **Delete**. Home tells you which files it changed and which it could not, and why.

## Your storage

The bar shows how much of your space you have used, by kind. Identical files count once. An admin can open **Everyone's storage** to see the whole home.
