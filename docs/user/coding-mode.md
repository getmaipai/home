# Coding mode

Home has two modes. You pick one in **Settings**, **Household**, **Coding**, in the row called **Home mode**.

**Normal** is how Home works today. Chat, pictures, videos and songs all run as usual.

**Coding** is for a big computer. Home loads one large model and gives it most of the memory. That one model writes code and also answers chat. Home turns the usual chat model off while it does this.

## Why it exists

A large coding model is smarter on hard tasks, but it is big. It needs about 85 GB of memory. The usual chat model and the other parts need about 36 GB. A 128 GB Mac cannot hold both. Coding mode makes room by letting the big model do both jobs.

## What changes while it is on

- Chat is answered by the large model. It may feel different from the usual chat model.
- Pictures, videos and songs wait. You see a message that Home is in coding mode.
- Voice and search keep working.
- For children and teens, chat works but without tools such as web search, and without thinking. That keeps their protections the same until the new model has been measured.
- Home uses about 91 GB of memory instead of 36 GB.
- Everything you made before stays where it is.

## What it needs

Coding mode needs a Mac with 128 GB of memory, Apple silicon and macOS 26.4 or later. Home checks eight things before it lets you switch. The row is greyed out until all eight are ready, and it tells you the first one that is not.

### Turn on coding

Coding must be on. Open **Settings**, **Household**, **Coding** and turn **Coding** on.

### Choose a coding engine

The coding engine must be Splash. Leave **Coding engine** on **Auto** and Home picks Splash on a Mac that can run it.

### Add the model files

Home needs the large model, its helper model and the engine files. Press **Install** in the checklist. The progress bar at the top shows the download. It is about 71 GB, so it can take a while.

### Check your computer

Your computer must be a 128 GB Mac with Apple silicon. Other computers can still use normal coding, but not coding mode.

### Make room in memory

The large model and the parts that stay on must fit in memory. Close big apps and check again. Home shows how much it needs.

### Test the coding model

Press **Run the test**. Home switches to coding mode, asks the model a few questions, then switches back. It takes a few minutes. The test must pass on this computer before you can switch for real, and it must be repeated after an update or after a week.

### Connect a coding app

At least one coding app must be connected, or you chose **Later** in setup. Make a personal key in **Settings**, **Coding**, then follow the lines it shows for OpenCode, Claude Code or Codex CLI. Home cannot install an app on another computer for you.

### Check coding speed

Home needs a recorded speed and quality check for the large model on this kind of computer. Until it is recorded, the mode stays off. Updates add this when it is ready.

## Switch it on

Pick **Coding** in the **Home mode** row. Chat shows that Home is switching. The switch takes a few minutes. The old chat model unloads first, then the large model loads and Home tests it.

## Switch it off

Pick **Normal**. The large model unloads, then the usual models load again.

## If a switch fails

Home puts everything back the way it was and adds an item to **Repairs** that says what went wrong. Open it, read the line, and press **Try again** when the problem is fixed.
