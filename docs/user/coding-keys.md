# Coding keys

Open **Settings**, then **My account**, then **Coding**. An admin must turn Coding on and allow your account before you can make a key.

## Make a key

Choose **Create key**, give it a name and pick when it should expire. Home shows the secret once. Copy it now and keep it private. Anyone with the key can use Coding as you.

The setup lines for OpenCode, Claude Code and other OpenAI tools appear with the new key. Copy the line for the tool you use. Home does not install that tool. Home may check each request. If an admin turns Coding off, your key stops working.

You can rename or revoke a key later. The key list shows its status, when it was made, when it expires, a short hint and when it was last used. A suspended key includes a reason. A key can stop working when it expires, Coding is paused, a part is missing or an admin changes your access.

## Your home address

At home, your tool connects to your Home address, such as `https://192.0.2.10/code/v1`. Use the home certificate if your computer asks you to trust it. Keys work away from home only when an admin turns on away access and you connect through the household's Tailscale network, such as `https://home.example.com/code/v1`.
