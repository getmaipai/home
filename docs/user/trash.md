# Trash

Open **Settings**, then **Data and privacy**, then **Storage** and **Trash**.
An admin can also open Storage from **Home settings**, **Storage and backups**.

Deleted media and playlists stay in Trash for 30 days. Pick **Restore** to put an item back.
You can restore an item until its keep date. After that, Home clears it within six hours, or the next time Home starts.

Pick **Delete forever** to remove an item now. Home asks you first. This cannot be undone.
The file on your drive stays where it is. Home remembers the deleted path, so a new scan does not add it back.
Restoring an item lets Home use that path again.

You see your own playlists and watchlists. An admin can also manage deleted items from the shared media library.
A child sees only their own items that are safe for a child. No one can change another person's playlists from Trash.

Lists and memories do not use this Trash yet.
