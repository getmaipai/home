# Bring back or delete something from Trash

Open **Settings**, then **Your data and apps**. On the **Data and privacy** tab, choose **Storage**, then press **Trash**. An admin can also open Storage from **Backups, storage and updates**.

Files you delete from the Library, deleted media and deleted playlists stay in Trash for 30 days. Each line says the day it is kept until. You can also open **Trash** inside the [Library](library.md). It lists your files.

## Bring something back

1. Find the item. Type in the search box to narrow the list.
2. Press **Restore**.

You can restore an item until its keep date. After that, Home clears it within six hours, or the next time Home starts.

## Delete something for good

1. Find the item.
2. Press **Delete forever**.
3. Press **Delete forever** again when Home asks. This cannot be undone.

For media from your own drive, the file on your drive stays where it is. Home remembers the deleted path, so a new scan does not add it back. Restoring an item lets Home use that path again. A deleted Library file is removed with the item.

## Who sees what

You see your own deleted files, playlists and watchlists. An admin can also manage deleted items from the shared media library. A child sees only their own items that are safe for a child. No one can change another person's playlists from Trash.

Lists and memories do not use this Trash.
