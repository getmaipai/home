# Set up voice recognition

Voice recognition can help MaiPai tell who is speaking. You can record a few short samples in **Settings → Account → Profile**.

Choose **Record a sample**, say a number or read a sentence in your usual voice, then choose **Stop recording**. You can add several samples. MaiPai turns each recording into numbers derived from your voice. The recording itself is not kept. The saved sample count appears on the page. Delete one sample beside it, or choose **Delete all samples** to remove them all.

The person being enrolled must be allowed to consent. A child cannot consent for themself. A teen must consent for themself. Guests cannot enroll. The server checks these rules too.

Your browser asks for microphone access while recording. If access is off, allow the microphone for this site in your browser settings, then try again.
