# Add a StackChan

An owner or admin can add a StackChan from **Settings**, then **Household**, then **Devices**.

First, turn on **Robots**. Then choose **Add a StackChan**. Use Chrome or Edge on a computer, and open Home at its secure `https` address. Phones and tablets cannot install the robot.

Plug the StackChan into the computer with a USB-C data cable. Choose its port when the browser asks. Home saves a backup of the robot before it changes anything. The backup may include the Wi-Fi password already saved on the robot. Home encrypts the backup as it arrives and keeps it with the robot's files.

Keep the robot connected while Home writes and checks the new software. When Home says it is ready, use a phone to join the Wi-Fi network named by the robot. Choose your home Wi-Fi in the page that opens. Home never asks you to type or share your Wi-Fi password.

The robot should come online in a few minutes. It needs to join the same Wi-Fi network as the Home computer. If it does not come online, check its Wi-Fi connection and press **Retry**.

## Cancel an install

If a robot has never come online, an owner or admin can choose **Cancel install** on its card. This revokes its one-time enrollment code and removes the robot and its saved flash backup. You can start again with **Add a StackChan**.

## Choose a robot's companion

An owner or admin picks how a robot talks. Open **Settings, Home, Devices**, open the robot, and look for **Companion and controls**.

1. **Controls** is child, teen or adult. It decides which companions the robot may use. A child robot can use child companions. A teen robot can use child and teen companions. An adult robot can use any companion.
2. **Companion** is the personality. Home ships three that share one lively, curious, friendly voice: Sprout for a child, Riff for a teen and Nova for an adult. The list shows only the companions the robot's controls allow.

The companion decides how the robot answers, and who is talking does not change that. A child companion answers like a kid's friend, with simple words and nothing grown-up. A robot with no companion answers with child controls.

If you pick a companion the controls do not allow, Home says so and tells you what to do. To lower a robot's controls, change its companion first.

The robot speaks in your Home's default voice. A child or teen companion always uses the built-in voice, never a voice made from a clip.
