# Coding settings for admins

Open **Settings**, then **AI and models**, then **Coding**.

## Turn Coding on

Coding is off when you first set it up. Turn it on to let people use the coding model on this computer. Adults may use it by default. You can change access for each person. A teen or child needs an admin grant. Their safety rules stay on.

The **Stop all coding now** button pauses requests. Keys stay in place. Press **Resume coding** when you are ready.

## Install the parts

The page lists the coding engine, model and any draft model. Each row shows its size and status. Press **Install** to get a part. Press **Remove** to free its space. Coding must be off before a part can be removed.

Home does not install a coding app. Each person chooses a tool and connects it with their own key. See [Coding keys](coding-keys.md).

## Limits and away access

The limits set how many requests can run, how often a key can call Home and how much thinking a request can use. A quiet model unloads after the set time. Chat always comes first. Coding waits or slows down, never chat. Open the [Status page](/status) to see what is running.

Coding keys work on the home network. You can allow them away from home through your household's Tailscale connection.
