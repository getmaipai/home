## 1. Primary and secondary, per feature

Every generating feature has a **Primary** model (what it uses by default) and a **Secondary** (the alternate): pictures FLUX 3 Image Klein and H3-Image; video LTX-2.5 and H3 (which of the two is Primary is the household's setting; section 6 gives the shipped default); music ACE-Step Turbo (Standard) with its XL and SFT builds as the tier steps and the next installed music model as Secondary; voice stays one model until a second is benched. The pair is data in the package (the engine catalog the Stack serves), not code. Settings, AI and models: each feature's card shows Primary and Secondary with an inline picker each (the existing card pattern), with size, readiness and one plain line of what each is better at ("quick, knows most characters" / "better at long words"). The setup wizard lists the Primary first and the Secondary as an optional second item with its true size and the one-line reason; skipping it keeps today's behaviour (Another take is a new seed). Nothing else is removed: Klein 4B, Z-Image, Qwen-Image and LTX stay installable and can be the Secondary instead (ERNIE is removed by ERNIE-REMOVE-01).

## 2. Choosing for one request: the Make with chip and phrasing

- **The chip:** adults get a "Make with" chip beside Quality in the one composer, in chat and on every Create page, listing the installed models of that feature (Primary first, "Automatic" first of all). It rides as part of the existing single composer hint and fills the new argument below. Children and teens never see it.
- **By phrasing:** "create me an image of the Terminator using FLUX" works because the **chat model** reads the words and fills the argument (rule 1: no regex, no word list reads "using"). The tool argument is `with`, a short enum of the installed model keys for that tool; the model is told which keys exist the same way it is told other typed options; an unknown or not-installed key is told to the person by the chat model in its own words (rule 6: a failed tool tells the model the failure kind; the model says it), with where to install it, and the picture is not made on a guess.
- **Tool size:** the argument is added to `generate_image`, `generate_video`, `generate_music` and the `edit_*` tools that remake a clip or song. It adds no tool (the one-composer ruling's condition 2: the hint never adds or removes an offered tool, the 16-tool budget is unchanged). `tests/turnMachine/toolsOfferedSize.test.ts` ceilings (generate_image and generate_video 1,500, generate_music 1,500, edit_music 2,100, edit_video 6,200) are never raised: the build measures first and buys the room by shortening existing descriptions; if the argument still does not fit, the row comes back to the architect for a new verdict (a hint-only fallback cannot work, because the chips fill arguments that must be in the schema). A minor's schema leaves `with` out (rule 8: the model never sees a control its person cannot use).
- **Age and surface gates first (rule 0):** unchanged; a child or teen's request ignores `with` and runs on their own lane's model.

## 3. Another take, retries and Make two

- **Another take** (the Library action and the card button) stays on the **same model** with a new seed: switching models costs a load (FLUX 3 loaded in 58 s cold and about 3 s warm in the bench), so it is a special case, not the common path. The Secondary is used in three cases only: the person asks for it ("Make with FLUX", the chip, or a separate "Try the other model" button on the card); a word picture failed the spelling check (below); and Make two, pick one. Where memory allows, both models stay resident (Boost and Max on a large computer), so a switch costs nothing; on small computers it shows "Switching model, a few seconds" and can be declined. The real switch cost per tier is measured in the build and shown on the card. Video: the same with H3 and LTX-2.5.
- **Automatic retry for words (W4):** when the read-back finds a missing word, **the other model takes the first retry** (with the text prompt below), a second retry goes back to the first model with the text prompt and a new seed, the take with the fewest missing words wins, and any word still wrong gets W4's one plain line. The text prompt (found in the research and the bench): the exact words quoted, "spell every word exactly as written, letter for letter, in a clean bold sans-serif typeface, large and high contrast, no other text anywhere, no extra letters, no misspellings". With one text-capable model: same model, text prompt, new seed, as in W4 plus the prompt.
- **Make two, pick one:** on request (a button) or automatically for a cover or poster on Boost and Max when the computer is idle, the Secondary's picture arrives after the first (the person is never made to wait for both) and the person picks the one they prefer; the other stays as an alternate in the creation record. The pick is a private count kept per household (counts only, never the prompt, the picture or a person: rule 6a), keyed by a request kind taken from declared data (the tool and its declared options, never read from the person's wording); it may later order the Primary choice (the model decides, never a word rule) and never leaves the Mac. Not on Reduced or Standard on a small computer, and clips are opt-in only.
- **Memory:** both models are not resident at once on small tiers; the switch costs a load of a few seconds; the Stack's tier admission decides, and a Secondary that cannot fit says so plainly and falls back to a new seed.

## 6. Defaults for a new install

The Primary and Secondary of section 1 are **per household data**. The shipped default for a new install: pictures FLUX 3 Image Klein primary and H3-Image secondary; video LTX-2.5 primary and H3 secondary; music ACE-Step Turbo then the next installed model. The default lives in the engine catalog (data). A household's own choice lives in its settings, always wins, and is made in Settings, AI and models; a household that prefers the other pair sets it there. No per-household preference is written into the repo, a migration or a default: nothing here names any particular install. The tier slots of [h3-tier-slots-2026-11-16.md](h3-tier-slots-2026-11-16.md) are written against "the Primary" and "the Secondary": each model's tier table applies to whichever role it holds. W1 ("the household's primary text-capable picture model") starts a word picture on the Primary and gives the other model the first retry. The setup wizard installs the Primary first and lists the Secondary as optional. Build: MODEL-PAIR-01 carries the shipped default; H3-SLOTS-STACK-01 and H3-SLOTS-HOME-01 never name a model as the default.
