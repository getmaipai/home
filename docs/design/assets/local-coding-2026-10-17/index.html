Coding with Home's own AI

Home can help the adults in the house write code. The AI runs on the home's own computer, so the code never goes to a cloud company.

The short version

  • An admin turns Coding on in Home settings. It is off until then.
  • Adults can use it. Guests never can. Kids and teens cannot in this version.
  • There are two ways to code: your own coding tool on your laptop, with a personal key, or the Code app in the browser.
  • Family chat always comes first. Coding waits or slows down, never chat.
  • Nothing goes on the internet unless you allow a site for a session.

Three screens

Coding settings

For admins. Turn coding on, pick who can use it, set how many sessions run at once, and stop everything with one button.

Your keys

Make a key for your coding tool. You see the key once. Copy the setup lines for Claude Code, Codex and others.

The Code app

Pick a project, describe the change, and watch it work. See every command, every changed line, and approve the plan first.

How the Code app keeps things safe

  • Each session runs in its own small, closed-off computer on the hub. It sees only that project.
  • It cannot see your family's chats, memories, photos or files, unless you add a folder yourself.
  • No internet unless you allow a site, like a package download site, for that session.
  • It never has your GitHub password. Only you can push or open a pull request, after you see the changes.
  • Home checks the changes for passwords and keys before anything is pushed.

What it is good at

Clear, small jobs: fix this test, add this field, write tests for this file. It is slower than the big cloud models and it does not make design choices well. Give it exact steps and check its work.
