This page is for owners and admins.

## 👤 Add a person

<Shot id="roles-users" />

1. Open **Settings**, then **Home settings**, then **Users**.
2. Under **Add someone**, type the person's name.
3. Pick a **Role**. The list shows only the roles you may create. An admin sees adult, teen, child and guest. An owner also sees admin and owner.
4. For an owner, admin or adult, type a **PIN or password**. They use it to sign in. Teens, children and guests need none.
5. Press **Add to household**.

If you skip the PIN for a role that needs one, Home says "This role requires a PIN or password. Enter one above, then try again." If something else fails, Home says "Could not add that person." Check the name is filled in, then try again.

The person's age group follows the role. A child gets child controls, a teen gets teen controls. See [People, roles and permissions](/docs/admin/how-it-works/people-roles-and-permissions).

## ✏️ Change a role or remove someone

- Only the owner can change a role. Open **Users** and pick the new role next to the name.
- To lock a person's session after idle time, tick **Require PIN lock** next to the name and set the timeout in minutes. The default is 5.
- To remove someone, press **Remove**, then **Yes, remove**. Home shows how many files only that person could see. Those files are deleted with them. Files other people can see stay with the household. For a child, you can download their files first. A person's own files are private, so ask an adult to save theirs.
- Home will not remove or demote the only owner.

## 🧒 A child's controls

Open **Family**, then the child's card. Two tabs are only for owners and admins:

| Tab | What you set |
|---|---|
| **Limits** | Daily minutes for each kind of app (Family, Fun, Health, Home, Info, Learning, Media, Robot body, Utilities). 0 means no limit. Also the child's storage. |
| **Topics** | **Sensitive subjects**. See [Safety settings](/docs/admin/people-and-safety/safety-settings). |

Changes save as you make them. The child cannot open either tab.

## 🧑 A teen's controls

There is no per-teen screen. Teen settings are household-wide and sit under Settings, Privacy and Search. A teen's own profile, chats and settings are private from admins.

## 🤝 When a child has a hard moment

Every adult gets a notice that "A check-in may help." It names the child and not what was said. This cannot be turned off.
