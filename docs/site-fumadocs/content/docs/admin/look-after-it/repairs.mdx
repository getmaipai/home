<Shot id="repairs" />

Only owners and admins can open Repairs. Anyone else sees a note that only an owner or admin can manage repairs.

## ✍️ Open Repairs

1. Open **Settings**, then **Backups, storage and updates**.
2. Open the **Maintenance** tab.
3. Choose **Repairs**.

Owners and admins also see a **Repairs** button on the Home screen. Each row shows the problem, how serious it is, what Home found, and the fix it offers.

## 🛠️ Run a fix

1. Open the row's menu.
2. Choose the fix. Its name is in the **Fix** column.

The row clears when the problem is gone.

## 🚫 Dismiss a problem

1. Open the row's menu and choose **Dismiss**.
2. Confirm.

Dismiss only what you do not need to fix.

## 🔁 Check again

- **Check my computers again** tests the computers that run the AI and updates the list.
- **Run setup again** opens the setup review so you can change your choices. Leaving it without a change saves nothing.
