## 🛠️ Repairs

Open **Settings**, **Home settings**, **Maintenance**, then **Repairs**. Home lists problems it found, such as web search failing, a backup copy failing or an engine reporting trouble. Each item may have a fix button, named for what it does, and has a **Dismiss** button.

- The fix button runs the repair Home offers. Not every item has one.
- **Dismiss** asks you to confirm, then hides the item.

Only an owner or admin can fix or dismiss. If a button fails, Home says "Could not fix that repair." or "Could not dismiss that repair." Reload the page and try again. If the list does not load, it says "Could not load repairs." Check Home is running and that you are signed in as an owner or admin.

Tick **Telegram me about new Repairs items** to hear about them when you are out.

## 🔁 When the AI stops by itself

An engine can stop on its own, for example when the computer runs low on memory. The Stack restarts it for you, after 2 seconds, then 10, 30 and 120 seconds. It checks that the engine answers before it calls it ready, and it waits while an install, an update or a picture or video job runs, or while memory is low.

- You get one notification: "Chat engine crashed and was restarted at 14:48; it was back in 12 seconds."
- **Status** shows how many times an engine crashed today and how many the Stack restarted.
- If Home cannot reach the Stack for 2 minutes, Home says "The AI stopped and is restarting itself". After 6 minutes it says "The AI could not restart itself: open Repairs".
- After 5 stops in 30 minutes the Stack stops trying. Repairs then shows "The chat engine keeps stopping" with the cause, the last 20 log lines and a **Restart engine** button. Fix the cause first (close big programs, or choose a smaller model), then press the button.

The switch is **Restart engines that crash** in the Stack settings (on by default).

| Symptom | Do this |
|---|---|
| Chat does not answer | Open **Engines**. If it says "No Stack configured", set the engine location. See [Use another computer for the AI](/docs/admin/install-and-set-up/use-another-computer-for-the-ai). |

## Health checks

Home checks itself the way a person would. Every few minutes it sends the AI a tiny made-up message ("hi"), asks it for the
weather, has the voice say a short phrase and the speech engine hear it, and, at most 3 times a day, asks it whether a public
website is down to see that web search still works. Open **Status** to see "Last checked 3 minutes ago: chat, tools, search,
voice, pictures" with a pass or fail dot for each. Choose **Run checks now** to run them yourself (the web search check runs
only if you ask for it).

- A check that fails twice in a row becomes one item in **Repairs** with what went wrong and what to do, and you get one
  notification. It clears itself when the check passes.
- The checks use a built-in "health" visitor that is not a person. Nothing it says or hears is saved: not in memory, history,
  feed, search history or notifications, and it is left out of usage counts.
- They wait while an install, an engine update, a picture or video job, or low memory is going on, and while someone is
  chatting.
- **Settings, AI, Keep the AI warm** turns the timers and the web search check off. It also keeps the AI's opening prompt
  ready so the first reply of the day is quicker. About 1,000 words of AI output an hour.

## 📄 Support report

Home can build a redacted report for you to attach when you ask for help. Open `/api/storage/diagnostics` while signed in as an owner or admin. It returns:

- Home's instance id, never the household's name.
- People: id, role, whether enabled, where they came from and when created. No names.
- Issue source, key, severity and times. No titles or details.
- Package ids, status and smoke test results.
- Household settings, without secrets.
- A storage summary.

It never contains conversations, memories, files or names. Read it before you send it.
