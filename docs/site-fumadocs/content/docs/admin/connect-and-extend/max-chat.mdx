title: Set up Max chat and coding
description: Turn on local coding, finish the Max chat checklist, and choose who may use Max.
---

Max chat gives one message the strongest answer Home can make. Home loads one large model and gives it most of the computer's memory. When nobody has used it for a few minutes, Home gives the memory back by itself.

## 👥 Who can use Max

Owners and admins can. An adult can when an admin has given them **Max**. Children and teens never can. While Max is on, pictures, videos and songs wait.

## ✍️ Set it up

1. Open **Settings**, **AI and models**, then the **Coding** tab.
2. Turn **Coding** on. Leave **Coding engine** on **Auto**.
3. Find **Max chat checklist**. Press **Install** to get the model files. It is about 71 GB.
4. Free memory if a row asks. Max chat needs a Mac with 128 GB of memory and Apple silicon.
5. Press **Run the test**. It takes a few minutes, and you can leave the page. Repeat it after an update or after a week.
6. Connect a coding app, or choose **Later** in setup.

People cannot pick Max until every row says **Ready**.

## 🔑 Connect a coding app

Each person makes a personal key in **Settings**, **Chat and AI**, **Coding** and follows the lines it shows for OpenCode, Claude Code or Codex CLI. Home does not install an app on another computer for you.

## 🎛️ Coding settings

On the **Coding** tab, **Stop all coding now** pauses requests, and **Resume coding** starts them again. Under **What Coding needs**, press **Install** or **Remove** on a part. Coding must be off to remove one. Limits set how many requests run at once. Chat always comes first.

## 💬 How people pick Max

In the message box, choose **Max** from the answer style control. A box asks **Use Max for this message?** and says it takes about a minute. Home hands it back about 3 minutes after the last answer. It always stops after 4 hours without use. Choosing **Instant** gives it back at once.

If it fails, Home puts everything back and chat keeps working on the usual model.
