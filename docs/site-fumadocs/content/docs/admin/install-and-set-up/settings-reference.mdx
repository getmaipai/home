<Callout type="info" title="How to read this page">
Settings has one column of pages. The top group, **Yours**, is for your own choices. The second group, **The home**, is for owners and admins and applies to everyone. Each heading below reads Page, then tab, then card. **Home** scope means set once for the household. **Person** scope belongs to one person, and the guardian rules decide who may change it for a child or teen. Level is **basic**, **advanced** or **expert**; the app hides higher levels until asked. A setting marked "Not active yet" is saved but nothing reads it today. Robot and vision settings (keys starting `robot.`, `person.robot.`, `person.vision.` and `vision.`) are used by MaiPai Bot, not by Home itself.

One more setting, **Wake word listening** (`voice.wakeword.enabled`, device scope, default off), shows under **Voice and robot**, then **This device**, only when the wake-word files are installed. Only owners, admins and adults see it. The one detector today is openWakeWord "Hey Jarvis", and it runs in the browser. No setup screen downloads the wake-word files; the setting stays hidden until all four are on disk in the `voice/wakewords` data folder (see [Where your data lives](/docs/admin/how-it-works/where-your-data-lives)).
</Callout>

Each table gives the label as shown, the key (useful in a support report), the default, the level and what it does. For the same screens in plain language, see the [user guide](/docs/user).
