The first time you open Home it starts a setup wizard. It has two parts: **Your Home** and **Your AI**. The installer opens the setup address in your browser when it finishes.

## 🪜 The screens

| Screen | What it does |
|---|---|
| Welcome | One line about Home. **Set up my Home**. |
| **Before you start** | Six notes you open one at a time: the AI can be wrong, the AI decides what it will make, a little care goes a long way, kids may still see things, people can grow attached to AI, and Home goes online for downloads, updates and searches you ask for. Press **I understand**. |
| **How should Home run?** | Pick **This computer** or **Another computer**. This computer starts the AI engine install at once. Another computer installs nothing here and is paired at the end. |
| **Choose where to store data** | Keep the defaults or pick a folder. Home refuses a folder it cannot use and says why. With two computers, the models folder belongs to the engine computer. |
| **Tune this computer** | Optional. Lists host changes for an always-on Mac (keep awake, restart after a power cut, keep Spotlight and Time Machine out of the models). Home applies the ones inside its own folders. Changes that need an administrator show the exact line to paste in Terminal. Each can be reverted. **Skip this step** leaves everything alone. |
| **Checking your computer** | Runs the checks and shows each as ready, to look at, or **Needs fixing**, with a plain summary. It never moves on by itself. Fix and press **Try again**. For two computers the title reads "computers". |
| **What this computer can do** | Only when the AI engine can already answer. A short table of which Boost and Max downloads fit here. **Continue**. |
| **Your setup plan** | What you get, including voice ("Voice: talk to Home"), and every part with its size. Parts you can skip have a checkbox and the total follows. A check under the list compares the total, plus 20 percent and install room, with the free disk space: green, amber (tight) or red (does not fit, with what to do). **Install and continue** starts the model downloads for the parts left on. |
| **Turn on web search** | Only when the Stack could not set up Home's own search. See below. |
| **Create your owner account** | Your name and a PIN or password (4 to 128 characters), typed twice. The boxes turn green with "Passcodes match" or red with the fix. |
| **Coding on this Home** | Choose **Set up coding** or **Not now**. Coding mode needs a Mac with 128 GB of memory. |
| **How should Home share this computer?** | Only when the AI engine can answer. Pick **Chat first**, **Balanced** or **Big jobs first**. Change it later under **Settings**, **AI and models**, **Performance**. |
| **Close apps for big jobs** | Only on a Mac used as a regular computer. Pick **Not now** or **Automatic**. |
| **Save your backup key** | **Download** only. **Continue** unlocks after the download starts. |
| **You're all set** | You can chat right away. With two computers, this screen also pairs the AI computer. |

The Face and Hello screens and the Away from home screen were removed. Turn on face greetings in your profile, and set up away access later in **Settings**, **Advanced**, **Network and access**.

Errors in the wizard show as a red alert that names the problem and the next step.

## ⬇️ Install progress

While the engine and models install, a one-line progress strip sits below the form (fetch, build, start, download). It stays at the bottom of every page for owners and admins until the install finishes. A failure shows the cause and a **Try again** button.

## 🔎 The web search step

Most installs never show it. When it does appear:

- Paste the address of your SearXNG, such as `http://192.0.2.10:8888`, and press **Test**. The result is one plain line with a **Recommended** line and a **Details** list. A warning still counts as working. **Continue** turns on only when the exact text in the box has passed a Test, and it saves the address.
- Leave the box empty and press **Continue** to skip. DuckDuckGo then turns on for adults. Teens and children use the Library until you allow more.

Details: [Set up web search](/docs/admin/connect-and-extend/web-search).

## 👑 The owner

The owner manages Home, its people, files and backups, and cannot be removed. Owner and admin roles need a PIN or password. See [People, roles and permissions](/docs/admin/how-it-works/people-roles-and-permissions).

If Home was already set up, the wizard says "Home is already set up. Sign in instead." If it cannot read its progress, it says "Home can't read its setup progress. Refresh this page. If it keeps happening, restart MaiPai Home on this computer or run the installer again."

## 📝 After setup

The Home screen shows up to three open setup steps under **Getting started**. Come back to them at your own pace.

1. Add your family: [Add people](/docs/admin/people-and-safety/add-people-and-parental-controls).
2. Check what leaves the house: [Privacy audit](/docs/admin/look-after-it/privacy-audit).
3. Allow the microphone the first time you use voice.

To review the AI computer, folder, checks and plan later, open **Settings**, then **Backups, storage and updates**. On the **Maintenance** tab, choose **Repairs**, then **Run setup again**.

For what the wizard looks like to a first-time user, see [Your first minutes](/docs/user/start-here/your-first-minutes).
