---
title: Make it easier to read
description: Pick a comfort style with bigger text, clearer colors or calmer motion.
---

## ✍️ Steps

1. Tap **Settings**, then **Appearance**.
2. Find the **Ease of use** card.
3. Under **Comfort style**, pick one:
   - **Standard**: MaiPai as it comes.
   - **Comfortable**: bigger words and more room.
   - **Large**: bigger words and buttons, stronger contrast.
   - **Simple**: bigger buttons, calm colors and helpers.
4. Watch the page change right away.

## 🎚️ Change one thing

Each row on the card changes one setting, like text size or motion. A row set to **Preset** follows your style. Change one row and the rest keep following.

After you change a row you see a line like "Large + 2 changes". Tap **Back to Large** to undo them.

## 🔒 A greyed-out row

If an admin set a row for you, it is greyed out and says so. Ask them if you want it changed.

<Callout type="info">These choices change comfort only. They never change what is safe or allowed.</Callout>
