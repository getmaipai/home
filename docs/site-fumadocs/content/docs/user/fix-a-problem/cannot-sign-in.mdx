## ✍️ Steps

1. Make sure you picked your own name from the list.
2. Type your PIN again. You see one box for each digit of your PIN, and Home signs you in when the last box is full. A wrong code shakes the boxes red and clears them.
3. If your sign-in is a longer password, tap **Use a password instead**. Type it in **Password** and tap **Sign in**.
4. To go back to digits, tap **Use a PIN instead**. To pick a different name, tap **Back**.
5. If it still fails, ask an admin to reset your PIN.

After 5 wrong tries in a row, the account locks. A countdown shows and the boxes stay off. The wait starts at 30 seconds and grows each time: 2 minutes, 10 minutes, then 1 hour. A right code clears the count. This is a real lock, so wait for the countdown to end before you try again.

## 🆕 A brand new install

If nobody has been added yet, MaiPai opens its setup instead. Ask the person who installed it.

## 🔐 Teens, children and guests

You may not need a PIN at all. Adults, admins and owners always do.
