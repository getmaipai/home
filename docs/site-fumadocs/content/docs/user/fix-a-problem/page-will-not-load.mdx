---
title: If a page will not load
description: What to try when MaiPai Home will not open or a page stays blank.
---

## ✍️ Steps

1. Check that your phone or computer is on your home Wi-Fi.
2. Reload the page.
3. Close the tab and open MaiPai Home again with the address the person who runs the house gave you.
4. Try a different browser.
5. If you see "Could not reach the hub.", the computer that runs MaiPai may be off or restarting. Wait a few minutes and try again.
6. Ask the person who runs the house to check that the computer is on.

<Callout type="info">Away from home, MaiPai only opens if an admin set up remote access.</Callout>
