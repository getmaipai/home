# LOCAL-BENCH-01: frame boost, upscale, cutout and depth (2026-11-06)

Mac Studio, no cloud call. Input: two 3 s clips (72 frames, 768x448, 24 fps) cut from a generated cat film: a close-up after a hard cut, and a wide of a boat. Peak memory is the macOS peak memory footprint.
Owner approved exactly these four models in chat on 2026-11-06. Work folder (not in the repo): `~/video-bench/bench01`, with the scripts, venvs and out/ videos and frame grids.

Caveats: `basicsr` 1.4.2 fails to import on current torchvision (the removed `functional_tensor`); the throwaway venv used a one-line patch, so an integration carries that patch or avoids `basicsr`. Evidence is thin: one subject type, one click, 3 s clips, no fast-motion clip, no HD or long-clip memory test.

## Ranking for an optional Stack component

1. **Real-ESRGAN x2** (a visible win, 2 to 3 GB, permissive). Becomes `edit_video` "upscale" (Higgsfield "Upscale").
2. **SAM 2.1 small** (one click follows a whole subject; 5 GB, Apache-2.0). The base for cutouts, relight of a subject and object replace.
3. **RIFE 4.25** (tiny and fast; only worth it for fast motion and slow motion, needs scene-cut skipping). Keep ffmpeg `fps_boost` until a fast-motion bench shows a gain.
4. **BiRefNet and Video Depth Anything Small** (11 and 19 GB peaks; use SAM 2 for video cutouts, BiRefNet only for stills).

Not run (not approved): lip sync, dubbing, motion transfer, replace (LOCAL-BENCH-02 and -03).
