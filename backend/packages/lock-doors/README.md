# Lock the Front Door

Ask MaiPai to lock the front door.

## Try it

- "lock the front door"
- "lock the door"
- "lock up the house"

Locking is a security action, so MaiPai always checks with you before
doing it - you'll be asked to confirm first.

## What it needs

Home Assistant, connected under Settings > Integrations, with your
front door lock set up there.

## What it uses

Talks directly to your own Home Assistant instance on your own network.
Nothing leaves the house.

## Offline

Needs Home Assistant to be reachable on your network.
