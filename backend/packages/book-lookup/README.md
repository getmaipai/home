# Book Lookup

Look up books by title or author.

## Who can use it

Teen and adult profiles can use this lookup. Child profiles cannot. A temporary chat's lookup can sit in the local cache until it expires.

## What it sends

It sends only the title or author as you said it to Library of Congress (loc.gov). It does not use a saved place or the household's home setting.

## Offline

This lookup needs the internet.
