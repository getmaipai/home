# Write a Document

Ask MaiPai to write something down - a packing list, a recipe, a short
story - and it shows up as a card you can read, ask for changes to, and
save.

## Try it

- "write me a packing list for the camping trip"
- "put this recipe in a document I can save"
- "can you turn this into a document"

Asking for a change to the same document edits it in place - a new
version, never a second copy.

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

The household's own conversation database, written through the
`artifact:write` permission. Nothing leaves the house.

## Offline

Works offline. Documents are stored locally.
