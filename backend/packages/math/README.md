# Math

Ask MaiPai to work out a math expression.

## Try it

- "calculate 15 * 12"
- "compute 2^10"
- "calculate sqrt(144)"

Standard notation only, not spoken-out words: `+ - * / ^` for the basic
operators, `sqrt()` for square root, `%` for percent. "15 times 12"
won't work; "15 * 12" will.

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

Nothing leaves the house - every calculation happens right here.

## Offline

Always works, even with no internet.
