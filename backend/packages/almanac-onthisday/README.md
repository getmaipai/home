# On This Day

Ask MaiPai what happened on this day in history.

## Try it

- "what happened on this day in history"
- "this day in history"
- "what's special about today in history"

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

Looks up today's date through Wikipedia, a free encyclopedia anyone can
read - never anything you say, only today's month and day. See the
household's Privacy page for the full "what leaves the house" row.

## Offline

Needs the internet - it can't answer without it.
