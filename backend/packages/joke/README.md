# Joke

A dad joke on demand, family-friendly every time.

## Try it

- "tell me a dad joke"
- "got any jokes"
- "make me laugh"

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

Joke fetches one joke from icanhazdadjoke.com, a free joke service, each
time you ask. Nothing personal is sent - just a plain request for a
random joke. See the household's Privacy page for the full "what leaves
the house" row.

## Offline

Joke needs the internet - it can't answer without it.
