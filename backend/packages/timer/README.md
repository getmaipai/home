# Timers

Ask MaiPai to set a timer.

## Try it

- "set a timer for ten minutes"
- "set a timer for an hour"
- "set a timer for 30 seconds"

Say a number and a unit: seconds, minutes, or hours.

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

Nothing leaves the house - the timer runs right here.

## Offline

Always works, even with no internet.
