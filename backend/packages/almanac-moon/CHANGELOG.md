# Changelog

All notable changes to the Sun and Moon package, in [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format.

## [0.2.0] - 2026-10-14

### Added

- Sunrise and sunset for the household home place, worked out locally.
- Moon illumination and upcoming full or new moon dates.

### Changed

- Moon phase uses Astronomy Engine instead of the former reference-date calculation.

## [0.1.0] - 2026-09-06

### Added

- Moon phase (session-d-packages-and-store.md step 7), calculated from
  a reference new moon and average month length before version 0.2.0.

### Added

- Typed, bounded result data for CHAT-16.
