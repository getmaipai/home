# Changelog

All notable changes to the Moon Phase package, in [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format.

## [0.1.0] - 2026-09-06

### Added

- Tonight's moon phase (session-d-packages-and-store.md step 7). One of
  the almanac's five small lookups. A standard astronomical
  approximation (days since a known reference new moon, divided by the
  synodic month), accurate to within about a day - no network call.
