# Edit a Picture

Tell chat what to change in a picture and it does it on this computer.
Nothing is sent anywhere.

When you change clothes or a background, Home checks that the faces stay the same.

## Try it

- "remove the man on the left"
- "make it sunny"
- "take the background out"
- "put these two pictures together"

A card shows the new picture. The first picture stays as it was. Tap Edit to
keep working on it.

## Who can use it

Everyone who can see a picture in the chat. Children keep the cartoon rules
for what they make.

## What it needs

The picture tools on this computer. An admin installs them in Settings,
Pictures and videos.

## Safety

Home blocks CSAM. Age and screen rules for pictures apply to every change.
