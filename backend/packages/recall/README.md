# Recall

Ask MaiPai what it remembers about something.

## Try it

- "what do you remember about the wifi password"
- "do you remember what I said about my allergies"
- "what have I told you to remember about pizza night"

Looks up what the household has saved in memory about a topic and
replies with it.

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

The household's own memory, read through the `memory:read` permission.
Nothing leaves the house.

## Offline

Works offline. Memory is local.
