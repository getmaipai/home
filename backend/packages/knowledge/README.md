# Knowledge

Ask MaiPai a general-knowledge question.

## Try it

- "who was Marie Curie"
- "what is photosynthesis"
- "tell me about the Eiffel Tower"

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

Knowledge looks up your question through Wikipedia, a free encyclopedia
anyone can read. See the household's Privacy page for the full "what
leaves the house" row.

## Offline

Knowledge needs the internet - it can't answer without it.
