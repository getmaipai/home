# Define

Ask MaiPai what a word means.

## Try it

- "what does curious mean"
- "define ambiguous"
- "what's the definition of ephemeral"

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

Define looks up the word through dictionaryapi.dev, a free dictionary
service, each time you ask. See the household's Privacy page for the
full "what leaves the house" row.

## Offline

Define needs the internet - it can't answer without it.
