# View Shopping List

Ask MaiPai what's on the household's shopping list.

## Try it

- "what's on my shopping list"
- "what do I need to buy"
- "read me the shopping list"

Reads back what hasn't been checked off yet. If the list is empty, says
so plainly.

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

Nothing leaves the house - your shopping list lives right here.

## Offline

Always works, even with no internet.
