# Bedtime storybook

Ask MaiPai to write a longer bedtime story - one with real chapters,
not just a few paragraphs - and it writes it in the background while
you keep talking, then drops a three-chapter storybook into the chat
when it's done.

## Try it

- "write a three-chapter bedtime story about a brave little fox"
- "can you write my kid a longer bedtime story with chapters"
- "make a whole bedtime storybook, not just one story"

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

The household's own chat model, run locally, to write the outline and
each chapter. The finished book is saved as an artifact through the
`artifact:write` permission. Nothing leaves the house.

## Offline

Works offline. The story is written by the household's own local model
and saved locally.
