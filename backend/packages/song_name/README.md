# Name that tune

Ask Home to identify a song playing near a connected robot, then discuss whether the guess is right. The package can listen, reject a guess, suggest a title, or confirm it. Song identification uses the household's configured providers and may require the person to approve an online lookup.

The package is available to child, teen and adult profiles. It does not require a robot for the smoke fixture; live listening does require a connected robot with a microphone.

Use the playback action when someone asks to pause, skip, repeat, change volume, like or save music; Home explains that playback controls are on the screen. For listening, include the person's own song-identification question in `question`.
