# Translate

Ask MaiPai to translate a word, phrase, or sentence.

## Try it

- "translate hello to spanish"
- "translate good morning into french"
- "translate thank you to japanese"

Say what you want translated, then the target language. Quality depends
on the household's own model - better for common languages, less
reliable for rare ones.

## What it needs

Nothing to set up. Works as soon as it's installed, using the household's
own local AI model.

## What it uses

Nothing leaves the house - the translation runs on the household's own
local chat model, the same one MaiPai uses to talk with you. A network
translation service is a separate, opt-in feature, not built yet.

## Offline

Always works, even with no internet - the model runs locally.
