# Changelog

## [0.1.3] - 2026-11-13

### Added

- Optional `takes` (1 to 3 different takes, made one after another and shown as one song card) and `seed` arguments, the same as the Create panel's Advanced drawer.

## [0.1.2] - 2026-11-02

### Added

- Optional `song_style`, `band` and `album` arguments: a song can be made in a saved song style or a made band's sound, and a song made for an album joins it when it finishes. The song's own words still win over the sound.

## [0.1.1] - 2026-10-18

### Changed

- A request for a song written, composed or sung now names the tool in its description, examples and lyrics argument, so the model calls it instead of answering with lyrics.

## [0.1.0] - 2026-10-17

### Added

- Local songs in chat with age and surface gates, original voices, private lyrics and version history.
