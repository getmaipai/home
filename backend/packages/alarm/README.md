# Alarms

Ask MaiPai to wake you or remind you at one time.

## Try it

- "wake me at 6:30"
- "set an alarm for 7 tomorrow called gym"

Say the time you want. You can add a short name, like "gym". This sets
one alarm. It does not repeat.

## What it needs

Nothing to set up. The alarm uses this home's clock.

## What it uses

The alarm label and time stay in this home. When it is time, MaiPai sends
you an in-app notice. A robot can also tell you if that notice is turned
on for robots.

## Offline

Setting an alarm works without internet.
