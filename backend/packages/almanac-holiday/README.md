# Next Holiday

Ask MaiPai when the next holiday is.

## Try it

- "what's the next holiday"
- "is there a holiday coming up"
- "when's the next public holiday"

## What it needs

Nothing to set up. Works as soon as it's installed. United States
holidays only for now - a way to change this per household isn't built
yet.

## What it uses

Looks up the next holiday through Nager.Date, a free public holiday
service. See the household's Privacy page for the full "what leaves the
house" row.

## Offline

Needs the internet - it can't answer without it.
