# Next Holiday

Ask MaiPai when the next public holiday is.

## Try it

- "what's the next holiday"
- "is there a holiday coming up"
- "when's the next public holiday"

## What it needs

Set the household Home place in Settings.

## What it uses

Holiday dates for the United States and Canada come from a yearly file included with the package. The household's Home place chooses the country. Other countries and dates outside 2026 to 2045 get a plain answer with a next step.

## Offline

Works offline. The yearly file is generated by `backend/scripts/gen-almanac-holidays.ts` and checked in with the package. Run `bun run scripts/gen-almanac-holidays.ts` from `backend/` to regenerate it. Change the script's year range constants to extend coverage.
