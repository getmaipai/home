# Birthday card format

Teaches MaiPai how to write a birthday card message: a warm opening, one real memory or wish, and a closing line.

## Try it

- "write a birthday card for my aunt"
- "help me write a card for my friend Nova"

## What it needs

Nothing to set up. Works as soon as it's installed. Everyone in the house can use it.

## What it uses

Nothing leaves the house. This is a set of plain instructions MaiPai
follows when writing a card, with no network call and no data collected.

## Offline

Works fully offline.
