# Remember

Tell MaiPai a fact and it will hold onto it for later.

## Try it

- "remember that I take my medicine at 8am"
- "remember I'm allergic to peanuts"
- "remember that Friday is pizza night"

Saves the fact to the household's memory so it can be recalled later.

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

The household's own memory, written through the `memory:write` permission.
Nothing leaves the house.

## Offline

Works offline. Memory is local.
