# Changelog

All notable changes to the Remember package, in [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format.

## [Unreleased]

### Added

- More ways to say it: "make a note that", "make a note of", "note that",
  "keep in mind", "don't forget that", "for future reference" and
  "remember:" save a fact the same way "remember that" does. The note's
  opener is dropped from what is saved.

## [0.1.0] - 2026-09-06

### Added

- Save a fact to the household's memory using the `memory:write`
  permission, so it can be recalled later.
