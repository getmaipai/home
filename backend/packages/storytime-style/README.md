# Storytime style

Teaches MaiPai how to tell a bedtime story: gentle, short, and never scary.

## Try it

- "tell me a bedtime story"
- "make up a story about a dragon"
- "tell a short story before bed"

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

Nothing leaves the house. This is a set of plain instructions MaiPai
follows when telling a story - no network call, no data collected.

## Offline

Works fully offline.
