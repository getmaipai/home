# Media Lookup

Ask MaiPai about a film or TV show.

## Try it

- "who directed Cobra"
- "what's the runtime of The Godfather"
- "tell me about the movie Breaking Bad"

## What it needs

Nothing to set up. Works as soon as it's installed.

## What it uses

Media Lookup looks up your question through Wikidata, a free public
database of facts, and Wikipedia, a free encyclopedia anyone can read.
See the household's Privacy page for the full "what leaves the house"
row.

## Offline

Media Lookup needs the internet - it can't answer without it.
