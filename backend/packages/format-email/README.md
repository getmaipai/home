# Email format

Teaches MaiPai how to write a good email: a greeting, the point up front, a clear ask and a sign-off.

## Try it

- "write an email to my landlord about the leaky sink"
- "help me email my teacher"

## What it needs

Nothing to set up. Works as soon as it's installed. Teens and adults can use it.

## What it uses

Nothing leaves the house. This is a set of plain instructions MaiPai
follows when writing an email, with no network call and no data collected.

## Offline

Works fully offline.
