Home speaker echo check

Use laptop speakers, not headphones. Set the volume to what you would really use to hear Home across a room (clearly loud, not quiet), and keep the laptop in its usual place. Stay quiet while each test runs.

The test plays a spoken sentence (or, if the server has no voice file, a voice-like noise) through the speakers and measures what the microphone hears. Nothing is recorded, saved, or sent anywhere.

You will also be asked to talk over the sentence once, to check that your own voice is not removed with the echo.

Path A uses the same Web Audio route as Home. Path B sends the same sound through a local pair of RTCPeerConnections into an audio player.
